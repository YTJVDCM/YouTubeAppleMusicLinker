# パネル開閉操作（TASK-008 / 0.2.2）

利用者の要望により、Apple Musicボタンを開閉トグルにした。初回表示で検索し、開いているときは同じボタンで閉じる。再度開くと既存の候補・エラー・検索中の状態を再表示し、新しい検索は発行しない。再検索は専用ボタンで明示実行する。動画が変わった場合は既存のSPA処理で表示内容を破棄する。

documentのcapture段階でクリックを確認し、閉じたShadow DOMでは内部クリックがホストへretargetされることを考慮してcomposedPathにホストが含まれるかで内外を区別する。パネル内部と起点ボタンのクリックでは外側判定による閉鎖を行わない。preventDefault/stopPropagationを使わず、外側クリック先のYouTube操作は継続する。外側クリック時はフォーカスを奪わず、閉じるボタン・Esc・トグルで閉じるときは起点ボタンへ戻す。aria-expandedも表示と同期する。

閉じる操作で進行中の検索を再発行・破棄しない。結果は閉じたパネル内に反映し、自動で開き直さない。

TASK-008はContent Script、既存DOM回帰テスト、版情報、対応文書をCodexが単独所有する。型検査と66件のテストでトグル、重複検索抑止、検索中の閉鎖、内外クリック、ページ側stopPropagationへの耐性、フォーカス、既存SPA抑止を確認。ビルド・web-ext lint・ローカルZIP作成も実施する。新しい外部通信・権限・依存追加はない。利用者ファイルは含めない。

利用者から0.2.1のiTunes検索正常動作の確認を受領した。MusicBrainz補助と0.2.2の開閉操作の実機確認は未実施。
