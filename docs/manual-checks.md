# Firefox実機チェック（部分確認済み）

## 利用者による確認結果

0.1.1のmanifest参照修正後、利用者から次の実機確認結果を受領した。

- 動画ページでボタンが表示されない問題は解消。
- アドオン設定画面への遷移は正常。
- 照合サーバーのURLが未設定のため、実カタログ検索・候補表示・Apple Musicへの遷移は未確認。

Firefoxバージョン・OS・実施日時の詳細は未報告。以下のチェック項目全体を合格としたものではない。

照合サーバーの初期値は空。実在する運用先を用意せずに外部送信先を設定しない。検索を確認するには、運用者がWorkerのAPPLE_MUSIC_TOKENシークレットとRATE_LIMITERを設定し、利用可能なHTTPSの/match URLをアドオンへ保存する。Tokenや署名鍵をアドオン設定へ入力しない。

## 事前準備

事前にnpmの型検査・テスト・ビルドを通し、リポジトリ直下のmanifest.jsonまたはdist/extension/manifest.jsonをFirefox Desktop 140以上へ一時読み込みする。直下版も生成ファイルを参照するためビルドは必須。自分のWorkerにDeveloper Tokenとレート制限を設定し、拡張設定にHTTPS /match URLを保存する。これらのデプロイ・実API送信は人間の判断で行う。

## ボタンが表示されない場合

1. about:debuggingでバージョンが **0.1.1以上** であることを確認する。0.1.0の直下manifestには参照切れがあった。0.1.1からは直下版・dist版とも読み込み可能。更新後のnpm run buildは必須。
2. about:debuggingでアドオンを再読み込みした後、既に開いていたYouTube動画ページも再読み込みする。
3. Firefoxの拡張機能メニューから本アドオンを開く。診断ポップアップで、YouTubeへの権限不足・Content Scriptの未応答・ボタン配置済みを区別する。権限許可やページ再読み込みは専用ボタンから明示操作で行える。
4. 未応答が続く場合、about:debuggingの本アドオンの「調査」から拡張側コンソールを確認する。ページ側コンソールにエラーがないことだけでは、注入済みとは判断できない。
5. ボタン配置済みなのに見えない場合、他の拡張機能やカスタムCSS、全画面表示の有無を確認する。

診断処理はカタログ検索・外部送信・Apple Musicへの遷移を行わない。

## 機能チェック

1. watchページでボタンが1個だけ現れる。ホーム画面・Shortsでは隠れる。クリック前にWorker・Apple Musicへ通信しない。
2. ボタンを押すとYouTube上のパネルに読み込み→曲・MV・アルバム・発売日・収録曲が現れる。ジャケット欠損時の表示を確認する。
3. 公式音源、長いイントロのMV、Live/Remix/Acoustic/Cover、feat.表記、日本語/英語、複数盤の曲を試す。MVは対応音源未確定となり、不確実な候補はユーザーが比較できる。
4. キーボードで各ボタンへ移動・実行できる。閉じる・Escで閉じ、起点ボタンにフォーカスが戻る。狭い画面でYouTube操作を妨げない。
5. 検索中に別動画へSPA遷移し、旧結果が表示されない。戻る/進む、通常ページへの遷移でも二重マウントしない。
6. 正しい候補を記憶し、再検索なしの再表示では優先される。明示的再検索で解除される。地域変更で混ざらず、全キャッシュ削除も動く。
7. Apple Musicタブなしでは新規作成。既存ありでは再利用。同一窓・最近使用優先、別窓再利用の設定とフォーカスを確認する。
8. pinned/audibleタブは既定で保護し、設定変更時だけ再利用する。連打して余分なタブが増えない。
9. Firefoxコンテナと通常/プライベートで混在再利用せず、新規タブも元の窓・コンテナを維持する。プライベート検索結果がstorage.localに残らない。Background停止後は再検索できる。
10. 未設定、接続拒否、オフライン、期限切れToken、429、5xx、候補なしでも明確な表示と再試行・手動検索がある。YouTubeの再生は継続する。
11. Apple Musicへの移動は「開く」か手動検索を押した場合だけ起きる。自動再生・録音・YouTube停止を行わない。
12. 配布物に秘密鍵・Tokenがなく、外部スクリプトを読み込まず、設定で許可したサーバーとApple由来ジャケットだけへ検索後に通信することを確認する。

実施日、Firefoxバージョン、OS、各項目の結果、問題の再現操作を記録する。未実施項目を合格扱いしない。
